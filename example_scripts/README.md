In here you will find example scripts to help you get started writing your own
scripts to work with `xwww` for various effects. Currently, there are scripts
for:

  * Randomly going through the images in a directory (xwww_randomize.sh)
  * Changing with which image `xwww` is initialized according to the time of day
  (xwww_init_according_to_time_of_day.sh)
  * Scheduling changes to the wallpaper at different times of day
  (xwww_scheduler.sh)
